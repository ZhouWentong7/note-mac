# 傅里叶变换和频域介绍
- 在傅里叶域进行图像处理i
> 傅里叶变换就是把信号从“时间/空间域”变换到“频率域”，
> 让我们看清楚信号中包含了哪些频率、每个频率的强度是多少

| **空间/时间域** | **频率域（傅里叶变换结果）** | **含义**                               |
| ---------- | ---------------- | ------------------------------------ |
| $f(t)$     | $F(\omega)$      | $f(t)$ 是原始信号，$F(\omega)$ 表示“每个频率的含量” |
| 快速变化的信号    | 高频成分大            | 变化快，对应高频                             |
| 平滑变化的信号    | 低频成分大            | 变化慢，对应低频                             |

傅里叶：一个周期性信号可以分为若干个正弦或余弦的形式

$f$表示空域信号， $F$表示频域信号。

正变换：
$$
F(u) = \int_{-\infty}^{+\infty} f(x) \, e^{-j 2\pi u x} \, dx
$$
反变换：

$$
f(x) = \int_{-\infty}^{+\infty} F(u) \, e^{j 2\pi u x} \, du
$$
 将连续信号进行采样，得到离散数据的傅里叶变换对，设：

- $f[n]$：离散时间（或空间）信号
- $F(\omega)$：频域连续信号（周期为 2\pi）

$$
F(\omega) = \sum_{n=-\infty}^{+\infty} f[n] \, e^{-j \omega n}

  $$$$
f[n] = \frac{1}{2\pi} \int_{-\pi}^{+\pi} F(\omega) \, e^{j \omega n} \, d\omega
$$

### 二维傅里叶变换变换对

正变换，将空域转为频域：
$$
F(u, v) = \sum_{x=0}^{M-1} \sum_{y=0}^{N-1} f(x, y) \, e^{-j 2\pi \left( \frac{ux}{M} + \frac{vy}{N} \right)}
$$

反变换，将频域转回空域：
$$
f(x, y) = \frac{1}{MN} \sum_{u=0}^{M-1} \sum_{v=0}^{N-1} F(u, v) \, e^{j 2\pi \left( \frac{ux}{M} + \frac{vy}{N} \right)}
$$

| **符号**  | **含义**         |
| ------- | -------------- |
| f(x, y) | 空域信号（图像强度、像素值） |
| F(u, v) | 频域信号（振幅与相位）    |
| M, N    | 图像的行数、列数       |
| x, y    | 空间坐标（离散）       |
| u, v    | 频率坐标（离散）       |
| j       | 虚数单位，j^2 = -1  |

计算出 F(u,v) 后，可分解为：
$$F(u, v) = R(u, v) + j I(u, v)$$
- $|F(u, v)| = \sqrt{R(u, v)^2 + I(u, v)^2}$
- $\phi(u, v) = \tan^{-1}\!\left( \frac{I(u, v)}{R(u, v)} \right)$
-
>[!NOTE] 直观理解
> - **空域（f）**：描述信号在“空间上的变化”（亮度、纹理等）。
> - **频域（F）**：描述信号在“频率上的组成”（平滑区域→低频，边缘→高频）。
>- 傅里叶变换 = 把“空间模式”分解为一系列“正弦波和余弦波”的加权组合。

性质
- F(0,0)=> 表示直流分量（DC分量），即图像的平均亮度与整体能量有关，归一化后等于图像的灰度均值。
- 平移性质：可以将频谱进行中心转换
	- $f(x,y)(-1)^{x+y} \quad \Longleftrightarrow \quad F(u - M/2, v - N/2)$:空域图像乘以$(-1)^{x+y}$对应的傅里叶变换，等于原频谱进行中心位移。
	- 频谱可视化时，使低频在中心、高频在四周，更符合人的直觉
- 旋转性不变性：空域图像旋转，频域图像以相同方向和角度旋转
- 可分性：连续两次一维傅里叶变换
- 分配性和比例变换性：
	- 空域缩小，频域放大
- 周期性、对称性

**边缘信号缠绕**
两个周期性信号进行卷积的时候发生。

在图像傅里叶变换（DFT）中，我们假设信号是 **周期性的（periodic)**。
也就是说：$f(x,y)$,于是当信号在边界“延拓”时，原本应该在图像外部的部分会被**折回**（wrap around）到另一边。

👉 就像一张图像被首尾相接地铺成一个“平面瓷砖”，所以边缘右侧的内容会“缠绕”到左侧，底部的内容会“缠绕”到顶部。

解决方法：对两个信号进行周期延拓
- 周期内不变
- 周期外：补0
- 使两个信号有相同的周期P：$P >= A+B -1$时，周期不会发生混叠

对于二维傅里叶变换
二维傅里叶变换中图像 $f(x,y)$（大小 $A×B$）和滤波器 $h(x,y)$（大小 $C×D$）进行扩展时的规则。
- 扩展周期$P ≥ A+C-1（x方向）$和$Q \ge B+D-1(y方向)$
- 扩展后的函数$f_e(x,y)和h_e(x,y)$在原函数定义域内取值为原函数，定义域外取值为0.

卷积定理（连续、离散）：时域（或空域）中的卷积等价于频域的乘积
$$时域（或空域）中的卷积 ⇔ 频域中的乘积$$
设二维离散信号：
$$f(x, y) \leftrightarrow F(u, v)$$
$$h(x, y) \leftrightarrow H(u, v)$$
则:
$$
f(x, y) * h(x, y) \ \leftrightarrow \ F(u, v) \, H(u, v)
$$
反之：
$$f(x, y) \, h(x, y) \ \leftrightarrow \ \frac{1}{MN} F(u, v) * H(u, v)
$$

| **空域** | **频域** | **说明**            |
| ------ | ------ | ----------------- |
| 卷积（模糊） | 乘法     | 卷积会把频率成分平滑掉（滤波效果） |
| 乘法（遮罩） | 卷积     | 空域乘法会导致频谱扩展或混叠    |
- **空间域卷积** 就是在频域中“按频率分量加权”；
- **频域乘法** 可以高效地实现图像卷积。

快速卷积例子：
- 空域的实现：$g(x,y) = f(x,y) * h(x,y)$
- 频域实现
	- $G(u,v) = F(u,v) \, H(u,v)$
	- 然后逆傅里叶变换：$g(x,y) = \text{IFFT}(G(u,v))$


滤波处理步骤：
1. 中心位移
	1. 乘以$(-1)^{x+y}$，
	2. 目的：将图像的低频成分（原本在频谱的左上角）移动到频谱中心；这样做是为了便于设计滤波器（如低通、高通等）在频谱中心作用
2. 图像的DFT**DFT（离散傅里叶变换）**，
	1. 得到频域表示
3. 滤波器函数H乘以频谱F
	1. 相当于空域的卷积（由卷积定理得出）
	2. 低通滤波器：保留低频，去除细节和噪声
	3. 高通滤波器：保留高频，增强边缘
4. 计算F和H的反DFT
	1. 得到经过滤波的空间域图像，但仍是中心化后的形式
5. 取实数部分
	1. 计算过程可能产生微小的虚部误差
6. $(-1)^{x+y}$乘以（5）的结果
	1. 回复原本的亮度分布位置
$$
\boxed{ \begin{aligned} f(x,y) &\xrightarrow{\times (-1)^{x+y}} f_c(x,y) \xrightarrow{\text{DFT}} F(u,v) \xrightarrow{\times H(u,v)} G(u,v) \xrightarrow{\text{IDFT}} g_c(x,y) \xrightarrow{\Re, \times (-1)^{x+y}} g(x,y) \end{aligned} }$$
>[!NOTE] 补充
> 1. 为什么两次中心化
> 	DFT默认低频在左上角，不方便滤波
> 		第一次：低频移到中心
> 		第二次：恢复原图位置
> 2. 为什么乘以滤波器函数就是滤波
> 	基于卷积定理，时域卷积=频域乘积

>[!important] 术语
>- **傅里叶变换**：是一种将时域或空域信号转换为频域信号的数学变换方法。通过傅里叶变换，可以将图像从空间域转换到频率域进行分析和处理。
>- **低频**：在频域中，低频成分主要决定图像中平滑区域的总体灰度级显示，反映了图像的大致轮廓和缓慢变化的部分。
>- **高频**：高频成分决定图像的细节部分，如边缘和噪声，反映了图像中快速变化的部分。


# 平滑的频域滤波器

> 低通滤波器


理想低通滤波器
$$
H(u,v)=

\begin{cases}

1, & D(u,v)\le D_0,\\

0, & D(u,v)>D_0.

\end{cases}
$$
- $D_0$：截止频率
- $D(u,v) = \sqrt{(u-\frac{M}{2})^2 + (v-\frac{N}{2})^2}$：频率平面矩阵中点到点（u，v）的距离
- 物理上不可实现
- 有振铃效应：滤波后的结果在边缘附近会出现波纹状的明暗起伏
	-  频域的“突然截断” → 时域的“无限振荡”
- 滤除高频成分使图像变模糊



## 巴特沃斯低通滤波器（Butterworth LPF)
> - 在通带（低频部分）保持尽可能平坦（无波动），
> - 在阻带（高频部分）尽可能快速衰减。

$$
H(u, v) = \frac{1}{1 + \left( \frac{D(u, v)}{D_0} \right)^{2n}}
$$
![[4-Butterworth.png]]
- n=1：没有振铃效应
- n> 2：振铃效应逐渐增大

总结
- 一阶：没有振铃
- 二阶：微弱振铃
	- 有效滤波且振铃可接受
- 增加：振铃加重
- n接近无穷：接近理想滤波器

## 高斯低通滤波器（**Gaussian Low-Pass Filter, GLPF**）

> 保留图像中的**低频分量（整体形状、平滑区域）**，
> 抑制**高频分量（边缘、噪声、纹理等）**。

$$H(u, v) = e^{-\frac{D(u, v)^2}{2 D_0^2}}$$
与理想低通不同，高斯滤波器没有“硬边界”，而是**平滑衰减**，避免了振铃效应（ringing）。

![[4-GLPF.png]]

代码实现
```python
import numpy as np
import cv2
import matplotlib.pyplot as plt

# 读取灰度图像
img = cv2.imread('example.png', 0)
M, N = img.shape

# 进行频谱中心化
f = np.fft.fft2(img)
fshift = np.fft.fftshift(f)

# 生成高斯低通滤波器
u = np.arange(M)
v = np.arange(N)
# uv分别存储所有点的水平和垂直坐标
u, v = np.meshgrid(u - M//2, v - N//2)
D = np.sqrt(u**2 + v**2)
D0 = 30  # 截止频率，可调
H = np.exp(-(D**2) / (2 * (D0**2)))

# 滤波
G = H * fshift
img_filtered = np.fft.ifft2(np.fft.ifftshift(G))
img_filtered = np.abs(img_filtered)

# 显示结果
plt.subplot(1,2,1), plt.imshow(img, cmap='gray'), plt.title('Original')
plt.subplot(1,2,2), plt.imshow(img_filtered, cmap='gray'), plt.title('Gaussian Low-Pass')
plt.show()
```

- 没有振铃效应
- 对应的空域滤波器也是高斯型的

补充：
- 高斯型
	- 一维： $G(x) = A \cdot e^{-\frac{x^2}{2\sigma^2}}$
	- 二维：$G(x,y) = A \cdot e^{-\frac{x^2 + y^2}{2\sigma^2}}$
	- - **圆滑、对称、没有突变**
	- - 中心值最大，越远离中心越小
	- - 控制参数 \sigma（标准差）决定“模糊程度”

# 同态滤波器
**背景**
在实际成像中，一幅图像 f(x,y) 可以表示为照度分量（illumination）与反射分量（reflectance）的乘积：

$f(x, y) = i(x, y) \cdot r(x, y)$

其中：
	•	$i(x, y)$：照度分量（光照强弱） → 变化缓慢 → 属于低频信息
	•	$r(x, y)$：反射分量（物体表面特性） → 变化剧烈 → 属于高频信息

乘积形式 $f = i \cdot r$ 在频域中**无法直接分离**，因为：

> 傅里叶变换的卷积定理只对加法成立，而非乘法。
>  $\mathcal{F}\{i(x,y) \cdot r(x,y)\} \neq \mathcal{F}\{i(x,y)\} * \mathcal{F}\{r(x,y)\}$



**目的**：将照射分量与反射分量解耦合

**同态滤波**：
- 频率过滤与灰度变换的结合。
- 照明反射模型为频率域基础
	- 压缩亮度范围与增强对比度来改善图像

通过**取对数 → 线性化乘积关系 → 再用傅里叶变换**，使得乘积变为加法：

$\ln f(x, y) = \ln i(x, y) + \ln r(x, y)$

###  同态滤波过程：
	1.	取对数变换：
	    $z(x,y) = \ln f(x,y) = \ln i(x,y) + \ln r(x,y)$
	2.	傅里叶变换：
		$Z(u,v) = I(u,v) + R(u,v)$
（现在是加法关系，可以用频率滤波器分离）
	3.	**设计滤波器** $H(u,v)$
目的：抑制低频（照度）增强高频（反射）
		$S(u,v) = H(u,v) \cdot Z(u,v)$
	4.	反变换：
		$s(x,y) = \mathcal{F}^{-1}\{S(u,v)\}$
	5.	指数还原：
		$g(x,y) = e^{s(x,y)}$

### 同态滤波器的设计
 常用的是高通型滤波器，例如改进的巴特沃斯高通滤波器：

$$H(u,v) = (\gamma_H - \gamma_L)\left[1 - e^{-c(D(u,v)^2 / D_0^2)}\right] + \gamma_L$$

参数含义：
	•	$\gamma_L < 1$：抑制低频（降低照度分量）
	•	$\gamma_H > 1$：增强高频（提高反射细节）
	•	$D_0$：截止频率
	•	$c$：控制过渡带宽度
