SwiGLU（Swish - Gated Linear Unit）是深度学习中的一种高级激活函数，尤其在大语言模型中应用广泛，如PaLM、LLaMA等。以下是具体介绍： - **原理与公式**：SwiGLU是GLU门控线性单元的变种，它将GLU中原始的Sigmoid激活函数替换为Swish激活函数。其公式为\(SwiGLU(x) = x_1 \cdot Swish(x_2)\)，其中输入向量\(x\)被拆分，分别用于Swish和门控操作。 - **计算过程**：输入张量首先通过两个权重矩阵（如\(W1\)和\(W2\)）进行线性变换，第一个线性变换的输出经过Swish激活函数，然后将其结果与第二个线性变换的输出进行逐元素相乘，从而得到最终结果。 - **优势**：SwiGLU利用一个可学习参数，能提供比传统函数（如ReLU）更平滑的过渡，增强了模型捕捉数据中复杂模式的能力。在预训练和下游任务中，相较于其他GLU变体表现更优，有助于提高模型性能和优化效果。 - **在模型中的应用**：SwiGLU本质上是对Transformer的FFN前馈传播层的第一层全连接和ReLU进行了替换。在LLaMA中，其FFN模块因SwiGLU从2个矩阵变成3个矩阵，为保持模型参数量大体不变，中间层维度通常会缩减为原来的2/3。 - **代码实现示例**：在HuggingFace LLaMA的源码中，在Decoder模块的LlamaDecoderLayer中的LlamaMLP引入了SwiGLU来改造FFN层，部分代码如下： ```python class LlamaMLP(nn.Module): def __init__( self, hidden_size: int, # 4096 intermediate_size: int, # 11008 hidden_act: str, # silu ): super().__init__() self.gate_proj = nn.Linear(hidden_size, intermediate_size, bias=False) self.down_proj = nn.Linear(intermediate_size, hidden_size, bias=False) self.up_proj = nn.Linear(hidden_size, intermediate_size, bias=False) self.act_fn = ACT2FN(hidden_act) def forward(self, x): return self.down_proj(self.act_fn(self.gate_proj(x)) * self.up_proj(x)) ```

Grouped-Query Attention（GQA）即分组查询注意力，是一种用于提升Transformer模型中注意力机制效率的方法，常用于实现大语言模型的更快推理。以下是具体介绍： - **原理**：GQA将查询头划分为g个组（\(1 \leq g \leq h\)，h为头的总数），每个查询头组被分配一个共享的键 - 值对，从而将不同的键值头数量从多头注意力（MHA）中的h个减少到g个。通过这种分组方式，GQA在推理过程中减少了存储和带宽需求。 
- **优势**：GQA旨在平衡标准多头注意力和多查询注意力之间的权衡。标准多头注意力以增加内存带宽开销和降低速度为代价来最大化准确性，而多查询注意力以准确性为代价来最大化速度和效率，GQA则可在一定程度上兼顾两者，在减少内存使用和推理时间计算的同时，对任务性能的影响较小。 
- **应用**：GQA在自然语言处理和计算机视觉等领域应用广泛。特别是在处理大量相关查询的场景中，如搜索引擎或大规模图像识别系统，通过分组处理查询，系统可以实现更快的响应时间和更高的吞吐量，这对于实时应用至关重要。
- **变体**：近年来GQA发展迅速，出现了QCQA、WGQA和DHA等变体，这些变体通过动态分组和优化的头合并策略，进一步增强了模型的适应性和准确性。
