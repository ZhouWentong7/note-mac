# 概述
定义：数字图像增强是通过特定算法处理图像，以**突出或去除特定信息**，从而提高图像的可读性和视觉效果。这一过程不增加图像信息，而是增强某些信息的可辨别能力，同时可能损失其他信息。

前提：不考虑图像降质




# 空间域图像增强

## 基于点处理的增强常用方法

- $r$:变换前的灰度值
- $s$:变换后的灰度值
**动态范围（Dynamic Range）指的是图像中亮度值从最暗到最亮之间的可表示范围**。
$$L = \frac{L_{max}}{L_{min}}$$
对数形式(分贝）：
$$(dB)=20\log(\frac{L_{max}}{L_{min}})$$
### 直接灰度变换

1. **线性变**
	- 反转变换(在$[0,L-1]$的灰度级范围内)： $s=(L-1)-r$
		- 适用于增强嵌入在一幅图中的白色或灰色细节，特别是在黑色作为主导地位时
	- 

2. **对数**： $s=clog(1+r)$
	 - c为常数
	 - $r \ge 0$
	 - 原图的动态范围太大，超出某些设备的允许动态范围，使用原图可能造成部分细节丢失
		 - 采用灰度压缩，如对数变换
	 - 灰度压缩
3. **指数**： $s=cr^{\gamma}$
	- $\gamma \lt 1$：提高灰度级，正比函数上方，变亮
	- $\gamma \gt 1$：降低灰度级，正比函数下方，变暗
4. **分段线性变换**(针对不同目标进行处理)
	- 对比度拉伸：增强各部分反差
		- 
	- 灰度分级
5. **比特平面分层**
	- 借助图像的位面，每个像素的灰度级是256，可以用8位表示，假设图像由8个1位平面组成，范围从位平面0到位平面7，0包含的像素最低位，7包含像素最高位
		- 通过对特定位提高亮度而改善图像质量
		- 较高位（前4位）：大多数视觉重要数据
		- 较低位（后4位）：微小细节
		- 分析每一位在图像中的相对重要性

- 以恒等变换的直线作为分界点
	- 恒等以上（如对数变换）：变换后比变换前值更大，所以图像增亮
	- 恒等以下：变暗
