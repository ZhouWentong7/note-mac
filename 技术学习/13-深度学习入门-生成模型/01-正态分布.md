## 基础

- 随机变量：取值由概率确认的变量
	- 大写字母表示
- 概率分布：所有可能的概率
	- $0 \le p(x_k) \le 1 (k=1,2,...N)$
	- $\sum_{k=1}^Np(x_k)=1$
	- 
- 观测数据（observation）：基于概率分布实际得到的每个值
	- 小写字母表示：x，y……
- 样本（sample）：观测值的集合
- 均匀分布（uniform distribution）：每个可能出现的值的概率相同

### 概率分布类型

- 离散型
	- 随机变量是离散的
	- $p(x)$:概率
- 连续型
	- 随机变量为连续值
	- $p(x)$:概率密度（概率密度函数）
		- x位于特定区间的概率 = 特定区间的曲线下面积（通过积分求得）
	- 对于所有x，概率密度都大于等于0：$p(x) \ge 0$
	- 概率密度在整个区间内的积分为1：$\int_{-\infty}^{+\infty} p(x)\, dx = 1$
### 期望值和方差
- 期望值：单次**观测得到**的**平均值**
	- 离散：$\mathbb{E}[x]=\sum_{k=1}^{N}x_kp(x_k)$
	- 连续：$\mathbb{E}[x]=\int_{-\infty}^{+\infty} xp(x)\, dx$
- 方差：随机变量的取值在期望值$\mu$附近的**偏离程度**
	- $Var[x]=\mathbb{E}[(x-\mu)^2]$
	- 越小，越接近期望
	- 离散
		- $Var[x]=\mathbb{E}[(x-\mu)^2]=\sum_{k=1}^N(x_k-\mu)^2p(x_k)$
	- 连续
		- $Var[x]=\mathbb{E}[(x-\mu)^2]=\int_{-\infty}^{+\infty}(x-\mu)^2p(x)dx$
	- 标准差（standard deviation）：方差取平方根后的值
		- 单位与原始数据相同，更直观

## 正态分布概述
- 正态分布（normal distribution)/高斯分布

### 正态分布的概率密度函数
#正态分布
正态分布的概率密度函数公式：
$$
p(x；\mu,\sigma)=\frac{e^{-\frac{(x-\mu)^2}{2\sigma^2}}}{\sqrt{2\pi}\sigma}
$$
- e:纳皮尔常数，约等于2.71828..
- p(x)：x为参数返回概率密度
- $\mu,\sigma$：参数

> 参数由人为设定，若由概率确定，这种方法也被叫做“贝叶斯方法”

正态分布：$$\mathcal{N}(x;\mu,\sigma)=\frac{e^{-\frac{(x-\mu)^2}{2\sigma^2}}}{\sqrt{2\pi}\sigma}$$
代码
```python
import numpy as np
import matplotlib.pyplot as plt

# 均值为0，标准差为1
def normal(x, mu=0, sigma=1):
    y = 1 / (np.sqrt(2 * np.pi) * sigma) * np.exp(-(x - mu)**2 / (2 * sigma**2))
    return y

x = np.linspace(-5, 5, 100)
y = normal(x)

plt.plot(x, y)
plt.xlabel('x')
plt.ylabel('y')
plt.show()
```
$$\mathcal{N}(x;\mu,\sigma)=\frac{e^{-\frac{x^2}{2}}}{\sqrt{2\pi}}$$
图像特点：
- 0为中心
- 左右对称
- 山形

## 中心极限定理
#中心极限定理 #central-limit-theorem

现象：无论$p(x)$是怎样的概率分布，随着样本大小的增加，**样本均值**$\bar{x}$的分布都会接近**正态分布**，方差是$p(x)$的方差的$\frac{1}{N}$。
![[01-central-limit.png]]

若$p(x)$是均值为$\mu$、方差为$\sigma^2$的概率分布，那样本均值$\bar{x}$的分布就接近于均值为$\mu$、方差为$\frac{\sigma^2}{N}$的正态分布。

```python
import numpy as np
import matplotlib.pyplot as plt

x_means = []
N = 5 # 样本大小

for _ in range(10000): # 采样次数
    xs = []
    for i in range(N):
    # 生成介于0~1的随机数
        x = np.random.rand()
        xs.append(x)
	# 计算均值
    mean = np.mean(xs)
    
    x_means.append(mean)

# normal distribution
def normal(x, mu=0, sigma=1):
    y = 1 / (np.sqrt(2 * np.pi) * sigma) * np.exp(-(x - mu)**2 / (2 * sigma**2))
    return y
x_norm = np.linspace(-5, 5, 1000)
mu = 0.5 * N
sigma = np.sqrt(1 / 12 * N)
y_norm = normal(x_norm, mu, sigma)

# plot
# density=True：纵轴表示概率密度；False：表示数据个数
# bins创建数据区间。
plt.hist(x_means, bins='auto', density=True)
plt.plot(x_norm, y_norm)
plt.title(f'N={N}')
plt.xlim(-1, 6)
plt.show()
```
