## GMM的数学公式
Review：
- 联合概率
- 条件概率

### 概率的复习
#联合概率 #条件概率
- **联合概率（joint probability）**:$p(x,y)=事件x和事件y同时发生的概率$
- **边际概率(marginal probability)**：p(x) 或p(y)是x或y单独发生的概率。
- **边际化**：联合概率中去除掉某些随机变量，就可得到边际概率
	- y是离散变量：$p(x)=\sum_y p(x,y)$
	- y是连续变量：$p(x)=\int p(x,y)dy$
- **条件概率（conditional probability）**:特定条件下的概率，$p(x|y)$
- 乘法定理：$p(x,y) = p(x|y)p(y)$
	- 将联合概率、边际概率、条件概率联合起来的公司


### GMM的数学公式

GMM**生成数据**的步骤：
1. 准备K个正态分布
2. 重复
	1. 基于某个概率分布，从K歌正态分布中选择其中一个
		- 分类分布(categorical distribution):$p(z=k;\phi)=\phi_k$
			- z离散随机变量，在1~ 之间取正数k
			- $\phi$分布参数
			- 第k个类别出现的概率
	2. 基于所选正态分布生成数据


>[!important] 生成模型的目标是表示观测数据x的概率分布`p(x)`。

#GMM定义
对于GMM，通过概率编计划，可以使用$p(x,z)$把p(x)表示为以下公式：
$$
p(x)=\sum_{k=1}^K p(x,z=k)
$$

结合联合概率，进行各种推导后得到：
$$
p(x,z=k)=\phi_{k}\mathcal{N}(x;\mu_l,\Sigma_k)
$$
由此可以看出，GMM就是每个正态分布乘以权重$\phi_k$，然后相加=正态分布的**加权和**。

### GMM的实现

官方代码
```python
def multivariate_normal(x, mu, cov):
    """
    定义多维正态分布函数
    param x: 输入数据，形状为(D,)
    param mu: 均值，形状为(D,)
    param cov: 协方差矩阵，形状为(D, D)
    return: 多维正态分布的概率密度值
    """
    det = np.linalg.det(cov)
    inv = np.linalg.inv(cov)
    d = len(x)
    z = 1 / np.sqrt((2 * np.pi) ** d * det)
    y = z * np.exp((x - mu).T @ inv @ (x - mu) / -2.0)
    return y

def gmm(x, phis, mus, covs):
    """
    计算高斯混合模型的概率密度值
    param x: 输入数据，形状为(D,)
    param phis: 各个高斯成分的权重，形状为
    (K,)
    param mus: 各个高斯成分的均值，形状为(K, D)
    param covs: 各个高斯成分的协方差矩阵，形状为(K, D, D)
    return: 高斯混合模型的概率密度值
    """
    K = len(phis)
    y = 0
    for k in range(K):
        phi, mu, cov = phis[k], mus[k], covs[k]
        y += phi * multivariate_normal(x, mu, cov)
    return y
```

## 参数估计的难点

### GMM的参数估计

和之前的单正态分布的最大似然推导过程类似，但是需要找到的参数除了均值和协方差之外，多了一个多个正态分布之间的权重向量，最大似然的参数也就变成了：$\theta = {\phi,\mu,\Sigma}$。

计算的过程仍然是取对数之后找到最大的参数，可是此时无法通过解析的方式求得，这个时候的公式变味了“log-sum”形式，很难解析。好解析的是“sum-log”形式
> 单一正态分布的log和exp会相互抵消，公式变得简单，而可以求解析解。log中存在两个以上的正态分布，最后的公式就会变得复杂，无法求解。

此时的解决方案：EM算法。
