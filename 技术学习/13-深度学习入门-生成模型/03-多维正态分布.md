## 多维正态分布概述

*多个实数值组成的向量的正态分布。*

### 多维正态分布的数学式

向量  x  的定义 $$ x = \begin{pmatrix} x_1 \\ x_2 \\ \vdots \\ x_D \end{pmatrix} $$
多维正态分布的概率密度函数 $$ \mathcal{N}(x; \mu, \Sigma) = \frac{1}{\sqrt{(2\pi)^D \left| \Sigma \right|}} \exp\left\{ -\frac{1}{2} (x - \mu)^{\top} \Sigma^{-1} (x - \mu) \right\} $$
- $\mu$：均值向量
- $\Sigma$：协方差矩阵
	- 是一个$D\times D$的矩阵
	- 对角线：每个变量的方差
		- $\sigma_{ii}$：随机变量$x_i$的“分散”程度
		-  $\sigma_{ij}$：随机变量$x_i$和$x_j$的关联
	- 非对角线：协方差
$$ \boxed{\mu} = \begin{pmatrix} \mu_1 \\ \mu_2 \\ \vdots \\ \mu_D \end{pmatrix} $$$$ \boxed{\Sigma} = \begin{pmatrix} \sigma_{11} & \sigma_{12} & \cdots & \sigma_{1D} \\ \sigma_{21} & \sigma_{22} & \cdots & \sigma_{2D} \\ \vdots & \vdots & \ddots & \vdots \\ \sigma_{D1} & \sigma_{D2} & \cdots & \sigma_{DD} \end{pmatrix} $$

#### 协方差 Covariance

$$
Cov[x_i,x_j] = \mathbb{E}[(x_i-\mu_i)(x_j-\mu_j)]
$$
- 可看做方差的泛化形式
- Cov是对称矩阵（转置后与原矩阵相等）
>[!note] 含义
> 两个向量之间的关联程度
> - 对角元素：自身变量的方差
> - 非对角元素：两个不同变量的协方差

$$

```


### 多维正态分布的实现

公式：$$ \mathcal{N}(x; \mu, \Sigma) = \frac{1}{\sqrt{(2\pi)^D \left| \Sigma \right|}} \exp\left\{ -\frac{1}{2} (x - \mu)^{\top} \Sigma^{-1} (x - \mu) \right\} $$

```python
# multivariate normal distribution
def multivariate_normal(x, mu, cov):
"""
x: (D,)
mu:(D,)
cov(D,D)
"""
    det = np.linalg.det(cov) # 计算行列式，是一个标量
    inv = np.linalg.inv(cov) # 计算逆矩阵
    D = len(x) # x是列向量，所以可以直接得到元素个数
    z = 1 / np.sqrt((2 * np.pi) ** D * det)
    y = z * np.exp((x - mu).T @ inv @ (x - mu) / -2.0)
    return y
```

- x列向量
- mu列项链
- cov列项链
- 利用广播特性计算

>np.meshgrid 是 NumPy 库的核心函数，用于将一维数组（x、y）转换为二维网格矩阵，为后续二维数据计算（如函数绘图、网格点分析）提供基础。

### 核心功能

将两个一维数组，转换为覆盖所有 (x_i, y_j) 组合的二维网格矩阵，即：

- 输入：x（长度为 M 的一维数组）、y（长度为 N 的一维数组）
- 输出：两个二维数组 `X` 和 `Y`，均为 (N, M) 形状
    - `X`：每行是重复的 x 数组，对应网格点的 “x 坐标”
    - `Y`：每列是重复的 y 数组，对应网格点的 “y 坐标”

### 二维正态分布可视化
```python
import numpy as np
import matplotlib.pyplot as plt

def multivariate_normal(x, mu, cov):
    # 定义多维正态分布函数
    det = np.linalg.det(cov)
    inv = np.linalg.inv(cov)
    D = len(x)
    z = 1 / np.sqrt((2 * np.pi) ** D * det)
    y = z * np.exp((x - mu).T @ inv @ (x - mu) / -2.0)
    return y

# 设置均值和协方差矩阵
mu = np.array([0.5, -0.2])
cov = np.array([[2.0, 0.3],
                [0.3, 0.5]])

# 生成网格点并计算对应的概率密度
xs = ys = np.arange(-5, 5, 0.1)
X, Y = np.meshgrid(xs, ys)
Z = np.zeros_like(X)

for i in range(X.shape[0]):
    for j in range(X.shape[1]):
        x = np.array([X[i, j], Y[i, j]])
        # 计算多维正态分布的概率密度
        Z[i, j] = multivariate_normal(x, mu, cov)

fig = plt.figure()
ax1 = fig.add_subplot(1, 2, 1, projection='3d')
ax1.set_xlabel('x')
ax1.set_ylabel('y')
ax1.set_zlabel('z')
ax1.plot_surface(X, Y, Z, cmap='viridis')

ax2 = fig.add_subplot(1, 2, 2)
ax2.set_xlabel('x')
ax2.set_ylabel('y')
ax2.contour(X, Y, Z)
plt.show()

```

- 均值决定山顶的位置
- 协方差决定山体宽度
	- x，cov\[0,0]决定X方向的广度
	- y, cov\[1,1]决定y方向的广度
	- 因为协方差是对称矩阵，所以设置`cov[0,1]=cov[1,0]`

#协方差
协方差矩阵
- 对角元素
	- 方差较大：分布沿其轴线跨度更大
- 非对角元素：
	- 若为正：分布沿着$y=x$倾斜
		- 变量成正相关关系
	- 若为负：分布沿着$y=-x$
		- 变量间存在负相关


## 多维正态分布的最大似然估计

### 进行多维正态分布的MLE计算
#多维正态分布 #多维最大似然
D维向量$x$的数学式如下定义：

$$ \mathcal{N}(x; \mu, \Sigma) = \frac{1}{\sqrt{(2\pi)^D \left| \Sigma \right|}} \exp\left\{ -\frac{1}{2} (x - \mu)^{\top} \Sigma^{-1} (x - \mu) \right\} $$

要知道这个函数的两个参数是我们的目的。

从这个正态分布中得到n个样本（离散的），得到如下转换（过程略）

$$
p(\mathcal{D};\mu,\sum) = \prod^N_{n=1}\mathcal{N}(x^{(n)};\mu, \sum)
$$
- $\mu, \sum$是参数
- 这个p是似然
- 找到拟合最好的时候的参数


可以转为log进行计算： $L(\mu,\sum)=\log p(\mathcal{D};\mu,\sum)$
- $L(\mu,\sum)$是标量，$\mu$是向量，$\sum$是矩阵
这样的求偏导计算也被称为梯度（gradient）
#梯度 

最后两个参数变为
$$
\hat{\mu} = \frac{1}{N}\sum^N_{n=1}x^{(n)}
$$
$$\hat{\boldsymbol{\Sigma}} = \frac{1}{N} \sum_{n=1}^{N} \left( \boldsymbol{x}^{(n)} - \hat{\boldsymbol{\mu}} \right) \left( \boldsymbol{x}^{(n)} - \hat{\boldsymbol{\mu}} \right)^{\top}
$$

| vector                                                                | shape |
| :-------------------------------------------------------------------- | :---: |
| $x^{(n)}$                                                             |  D,1  |
| $x^{(n)}-\hat{\mu}$                                                   |  D,1  |
| $\left( \boldsymbol{x}^{(n)} - \hat{\boldsymbol{\mu}} \right)^{\top}$ |  1,D  |

### 实现最大似然估计

```python
import os
import numpy as np
import matplotlib.pyplot as plt

path = os.path.join(os.path.dirname(__file__), 'height_weight.txt')
xs = np.loadtxt(path)

# Maximum Likelihood Estimation(MLE)
mu = np.mean(xs, axis=0)
cov = np.cov(xs, rowvar=False)

def multivariate_normal(x, mu, cov):
    det = np.linalg.det(cov)
    inv = np.linalg.inv(cov)
    d = len(x)
    z = 1 / np.sqrt((2 * np.pi) ** d * det)
    y = z * np.exp((x - mu).T @ inv @ (x - mu) / -2.0)
    return y

small_xs = xs[:500]
X, Y = np.meshgrid(np.arange(150, 195, 0.5),
                   np.arange(45, 75, 0.5))
Z = np.zeros_like(X)

for i in range(X.shape[0]):
    for j in range(X.shape[1]):
        x = np.array([X[i, j], Y[i, j]])
        Z[i, j] = multivariate_normal(x, mu, cov)

fig = plt.figure()
ax1 = fig.add_subplot(1, 2, 1, projection='3d')
ax1.set_xlabel('x')
ax1.set_ylabel('y')
ax1.set_zlabel('z')
ax1.plot_surface(X, Y, Z, cmap='viridis')

ax2 = fig.add_subplot(1, 2, 2)
ax2.scatter(small_xs[:,0], small_xs[:,1])
ax2.set_xlabel('x')
ax2.set_ylabel('y')
ax2.set_xlim(156, 189)
ax2.set_ylim(36, 79)
ax2.contour(X, Y, Z)
plt.show()```
